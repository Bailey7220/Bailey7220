## Projects

### Retail Sales & Profitability Analysis | SQL

SQL portfolio project analyzing synthetic multi-channel retail data across 44,290 order lines and 14,671 orders. Uses a seven-table SQLite dataset, joins, CTEs, aggregations, window functions, and KPI calculations to investigate revenue, gross profit, margin, returns, channel/category performance, and monthly target attainment.

Highlights: $25.91M revenue after discounts | $6.61M gross profit | 25.50% gross margin | 14,671 orders analyzed

Revenue and gross profit are not adjusted for customer returns. Gross profit is not net profit. The repository documents calculation choices, targeted validation, and remaining reproducibility limitations; full end-to-end execution of the committed workflow is not yet verified.

Skills: SQL, Data Analysis, Data Modeling, KPI Reporting, Microsoft Power BI, Microsoft Excel

[Repository](https://github.com/Bailey7220/Retail-Sales-Profitability-Analysis-SQL)

*Built on synthetic retail-sales data for portfolio purposes. No real company, customer, or transaction data. Findings do not represent real business impact.*
